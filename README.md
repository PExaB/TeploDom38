# Теплоконтур

Готовый адаптивный лендинг на Next.js. Проект можно открыть и редактировать в VS Code на Windows, macOS или Linux.

## Стек

- Next.js 16 и React 19;
- TypeScript;
- Tailwind CSS 4 и обычный CSS;
- Zod для проверки данных формы;
- Resend для отправки заявок на корпоративную почту.

## Запуск в VS Code

1. Установите Node.js 22 или новее.
2. Откройте эту папку в VS Code.
3. В терминале выполните:

   ```bash
   npm install
   npm run dev
   ```

4. Откройте `http://localhost:3000`.

## Настройка заявок на почту

1. Зарегистрируйтесь в Resend и подтвердите домен компании.
2. Создайте API-ключ.
3. Скопируйте `.env.example` в `.env.local`.
4. Заполните значения:

   ```env
   RESEND_API_KEY=re_xxxxxxxxx
   LEAD_RECIPIENT_EMAIL=info@company.ru
   LEAD_SENDER_EMAIL="Сайт компании <site@company.ru>"
   ```

`LEAD_RECIPIENT_EMAIL` — почта компании, на которую должны приходить заявки. `LEAD_SENDER_EMAIL` — адрес на подтверждённом домене, от имени которого сайт отправляет письма.

Форма передаёт имя, телефон, площадь, толщину слоя и рассчитанную стоимость. Секретный ключ используется только в серверном обработчике `/api/lead` и не попадает в браузер.

## Проверка и публикация

```bash
npm run lint
npm run build
```

Проект удобно размещать на Vercel. При публикации добавьте там те же три переменные окружения.
